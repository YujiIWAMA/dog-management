# わんこ手帳

犬の体重・ごはん・予定を夫婦で共有するPWA（家計簿アプリと同じ構成：Firebase＋Cloudflare Pages）。

## 機能
- 体重の記録と折れ線グラフ（1ヶ月／半年／1年／全期間）
- カレンダー：予定・メモ（病院・ワクチン・お薬・トリミングなど）を書ける
- 体重・ごはん変更を記録すると、その日付のカレンダーに表示
- 誕生日・うちの子記念日・お迎え100日ごとを自動でカレンダーに表示
- ヘッダーに年齢（○歳○か月○日）と「お迎えして○日目」
- 招待コードで夫婦共有（リアルタイム反映・オフラインでも閲覧可）

## 公開手順（家計簿と同じ流れ）
1. **Firebaseプロジェクトを新規作成**（例：wanko-techo）
   - Authentication → ログイン方法 → **Google** を有効化
   - Firestore Database → 作成（本番モード、リージョンは asia-northeast1）
   - Firestore → **ルール** タブに `firestore.rules` の中身を貼って公開
   - プロジェクトの設定 → マイアプリ → ウェブアプリを追加 → 表示される設定値をコピー
2. `index.html` の上の方にある `FIREBASE_CONFIG` に設定値を貼り付け
   （設定前はデモモードで動き、データはその端末だけに保存されます）
3. GitHubに新しいリポジトリ（例：wanko）を作り、このフォルダの中身を全部アップロード
4. Cloudflare Pages → GitHub連携でそのリポジトリを選んで公開（ビルド設定は不要）
5. Firebase → Authentication → 設定 → **承認済みドメイン** に `○○.pages.dev` を追加

## 夫婦で使い始める
1. 自分がログイン → 「新しく始める」 → プロフィール（名前・誕生日・お迎え日・写真）を登録
2. ぷーあるタブ → 「招待リンクを送る」で奥さんにLINE等で送信
3. 奥さんがリンクを開いてログイン → 「参加」を押すだけ
4. それぞれ Safari の共有ボタン → 「ホーム画面に追加」でアプリ化

## ファイル
- `index.html` … アプリ本体
- `manifest.json` / `sw.js` / `icons/` … ホーム画面アプリ化・オフライン用
- `firestore.rules` … 家族メンバーだけが読み書きできるルール
